# TC-104 Overlapping request is refused

- **Feature:** Leave requests
- **Priority:** High

## Preconditions

- Calendar is empty
- User alice (employee)

## Steps

1. Sign in as alice
2. Request ANNUAL leave from 2026-11-02 to 2026-11-06
3. Request SICK leave from 2026-11-05 to 2026-11-09

## Expected result

- The second request shows the error "These dates overlap another request"
- The table still holds only one request
- Annual leave left still shows 19
