# TC-105 Manager approves a pending request

- **Feature:** Approval
- **Priority:** High

## Preconditions

- Calendar is empty
- Users alice (employee) and maria (manager)

## Steps

1. Sign in as alice
2. Request ANNUAL leave from 2026-11-02 to 2026-11-03
3. Log out
4. Sign in as maria
5. Approve request 1

## Expected result

- Request 1 shows status APPROVED
- The Approve and Reject buttons of request 1 are gone
- Maria does not see the new-request form
