# TC-106 Employee cancels a pending request and gets the days back

- **Feature:** Leave requests
- **Priority:** Medium

## Preconditions

- Calendar is empty
- User alice (employee)

## Steps

1. Sign in as alice
2. Request ANNUAL leave from 2026-11-02 to 2026-11-04
3. Cancel request 1

## Expected result

- Request 1 shows status CANCELLED
- Its Cancel button is gone
- Annual leave left is back to 24
